# Daily Skill Combos

这是你日常最值得反复使用的 skill 组合。目标不是全都记住，而是遇到场景时直接套。

## 论文与研究

### 1. 论文写作组合

- `create-plan`
- `content-research-writer`
- `edit-article`

适合：

- 开始写一章
- 写相关工作
- 把资料变成段落

### 2. 文献深挖组合

- `hv-analysis`
- `meeting-notes-and-actions`

适合：

- 系统研究一个方向
- 整理读文献后的结论
- 把导师讨论转成后续动作

### 3. 答辩材料组合

- `paperjsx`
- `spreadsheet-formula-helper`
- `pdf`

适合：

- 做答辩 PPT
- 整理实验结果页
- 检查最终提交材料

## 代码与项目

### 4. 功能开发组合

- `create-plan`
- `tdd`
- `webapp-testing`

适合：

- 写新功能
- 做页面流程
- 边开发边验证

### 5. Bug 排查组合

- `diagnose`
- `zoom-out`

适合：

- 报错原因不明确
- 修了几次都不对
- 想先理解系统位置再下手

### 6. 需求澄清组合

- `grill-me`
- `planing-with-file`

适合：

- 自己还没想清楚需求
- 想先问清楚再开工
- 想把确认过的计划落到 `plan.md`

## 收尾与整理

### 7. 阶段收尾组合

- `file-organizer`
- `neat-freak`

适合：

- 一周结束
- 一个模块做完
- 准备交导师或交同学

### 8. 会议复盘组合

- `meeting-notes-and-actions`
- `meeting-insights-analyzer`

适合：

- 导师会
- 组会
- 项目讨论

## 最省心的使用方式

你平时不需要手动点名 skill，只要直接说场景：

- “帮我写论文这一节”
- “帮我研究一下这个方法”
- “帮我做答辩 PPT”
- “帮我实现这个功能”
- “这个 bug 很难查，按系统流程来”
- “这个阶段做完了，帮我整理一下”

我会按这里的组合自动选用合适的 skill。
