# Install Commands

这些命令用于在新电脑上补装当前未保存副本、但你已经登记过的第三方 skills。

## 来自 ComposioHQ/awesome-codex-skills

```powershell
git clone https://github.com/ComposioHQ/awesome-codex-skills.git
```

可手动复制需要的目录到 `~/.codex/skills`，或按仓库 README 使用其 skill 安装方式。

## 来自 mattpocock/skills

```powershell
git clone https://github.com/mattpocock/skills.git
```

可从 `skills/skills/engineering`、`skills/skills/productivity`、`skills/skills/misc`、`skills/skills/personal` 中复制需要的 skill。
